# Cricket Mania 🏏

Cricket Mania is a simple yet engaging Java-based cricket game with a graphical interface built using Java Swing. Players can enter their names, perform a toss to determine the batting order, and play a quick six-ball match while avoiding getting out. The game automatically keeps track of scores and announces the winner. It features an interactive GUI, randomized gameplay, and easy controls.

## How to Play 🎮
1. Start the game by entering player names.
2. Toss to decide who bats first.
3. Bat by entering runs (0-6) each turn.
4. If the entered run matches the computer's number, the player is out.
5. The player with the highest score wins!

## Installation 🔧
1. Clone this repository: `git clone https://github.com/your-username/Cricket-Mania.git`
2. Compile the Java file: `javac CricketGameGUI.java`
3. Run the game: `java CricketGameGUI`

## Requirements 📋
- Java 8 or later installed.

Enjoy playing Cricket Mania! 🏆
